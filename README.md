# Software FJ – Sistema Integral de Gestión de Clientes, Servicios y Reservas

Proyecto del curso **Programación (213023) – UNAD**, Fase 4: Componente práctico – Prácticas simuladas.

Sistema orientado a objetos, **sin base de datos**, que gestiona clientes, servicios (salas, alquiler de equipos y asesorías) y reservas, con manejo avanzado de excepciones y registro de eventos en un archivo de logs.
